# homebrew-tap

Homebrew tap for the TerraScale `ts` CLI.

## Layout and checks

- `Formula/ts.rb` is generated by each ts-go CLI release and written by the `sync.yml` workflow after it checks URLs and checksums. Do not edit it by hand.
- Fast tests: `for f in Formula/*.rb; do ruby -c "$f"; done` (CI runs the same syntax check).

Workspace rules (hosting, secrets, models, Cloudflare, GitHub and shipping) are in the **Shipping code** section of the TerraScale workspace AGENTS.md.
